# GST Billing Platform

A **GST-compliant billing platform** built with **FastAPI, Vue 3, and PostgreSQL**, designed using a **microservice-ready architecture** with **CA-grade tax calculations** and a **Tally-compatible accounting layer**.

This repository currently implements **MVP-1**, focused on **Sales Billing**, while being fully extensible for purchases, OCR, GST returns, and Tally integration.

---

## 🚀 Key Highlights

- 🇮🇳 Indian GST compliant (CGST / SGST / IGST)
- 🧾 Professional invoice generation (PDF/Print)
- 🧠 Backend-driven tax calculation (CA-safe)
- 📒 Accounting-first design (Voucher & Ledger based)
- 🧩 Microservice-ready (Modular Monolith for MVP)
- 🔮 Future-ready for Tally, OCR, WhatsApp, and GSTR
